# Smart ATM System

A console-based Smart ATM system developed using C programming. 
The project simulates basic ATM operations such as account creation, 
login, deposits, withdrawals, money transfers, PIN management, and 
transaction history.

## Features

- Create a new bank account
- Generate a unique account number
- Login using account number and PIN
- Check account balance
- Deposit money
- Withdraw money with balance validation
- Transfer money using OTP verification
- Change PIN
- View mini statement and transaction history
- View account details
- Exit the ATM system

## Technologies Used

- C Programming
- Standard C Library

## Concepts Used

- Functions
- Arrays
- Conditional statements
- Loops
- Switch-case
- User input and output
- Random number generation
- Basic transaction management

## How It Works

1. The user creates an account by entering their name, PIN, and initial balance.
2. The system generates an account number.
3. The user logs in using the account number and PIN.
4. After successful login, the user can select different ATM operations.
5. Deposits, withdrawals, and transfers are recorded in the transaction history.

## How to Run

1. Download or clone this repository.
2. Open `smart_atm.c` in a C compiler or IDE.
3. Compile the program.
4. Run the generated executable.

## Project Purpose

This project was developed to practice C programming and understand 
how functions, arrays, loops, conditions, and transaction handling 
can be used to build a real-world application.
